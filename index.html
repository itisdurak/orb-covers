Как это сделано

Ни одного стока.
Только математика.

Картинки рисует один Node-скрипт: градиенты, сферы и сетки считаются по пикселям, затем собираются в PNG собственным энкодером на zlib.

01

Свой PNG-энкодер

CRC32, чанки IHDR / IDAT / IEND и deflate из стандартной библиотеки. Ни одной npm-зависимости.

02

Сид вместо случайности

Каждая сцена воспроизводится по seed. Поменяйте число — получите другой вариант в той же палитре.

03

Композиция под кроп

Главный объект держится в центре или на безопасной стороне, поэтому 9:16, 1:1 и 3:1 не ломаются.

tools/generate.js 
$ node tools/generate.js

# 8 сцен → images/*.png + manifest.js
# свой PNG-энкодер: zlib + CRC32
# без npm, без стоков, без внешних сервисов
