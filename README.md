# orb.studio — где использовать сгенерированные картинки

Витрина из восьми процедурно сгенерированных PNG-обложек и восьми макетов,
которые показывают, где эти изображения работают: hero-блок, пост в соцсетях,
stories, аватар, OG-превью, баннер, карточка товара и шапка письма.

**Сайт:** https://itisdurak.github.io/orb-covers/

## Что внутри

```
index.html            — страница-витрина
styles.css            — оформление и макеты
app.js                — лайтбокс, прогресс скролла, анимации
images/               — 8 + 1 PNG (сгенерированы скриптом)
images/thumbs/        — лёгкие JPEG-превью для галереи и списка файлов
images/manifest.js    — размеры, палитры и сиды
tools/generate.js     — генератор: сцены, свой PNG-энкодер на zlib
tools/shot.js         — QA-скриншоты через Edge DevTools (не нужен для сайта)
generated-images.zip  — все PNG одним архивом
```

## Генерация

Нужен только Node.js, без npm-зависимостей:

```bash
node tools/generate.js
```

Скрипт перерисует все изображения по сидам и обновит `images/manifest.js`.
Палитру, сид, сцены (градиенты, сферы, кольца, сетки) можно менять в массиве
`IMAGES` в конце `tools/generate.js`.

## Локальный просмотр

Страница статическая, можно открыть `index.html` напрямую в браузере.
Для корректной работы со скачиванием ZIP лучше поднять локальный сервер:

```bash
npx serve .
```
